# StudentRiskFrontend

Frontend for the Academic Risk Prediction project, built with React and Vite.

## Local development

1. Install dependencies:
   `npm install`
2. Create a `.env` file if needed:
   `VITE_API_BASE_URL=http://localhost:8086/api`
3. Start the app:
   `npm run dev`

## Production deployment

Set this environment variable in Vercel:

`VITE_API_BASE_URL=https://YOUR-BACKEND-URL/api`

Build command:
`npm run build`

Output directory:
`dist`
